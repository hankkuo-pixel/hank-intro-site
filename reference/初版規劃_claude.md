## 一、設計總則

沿用 haoqi 的視覺語言，換成 Hank 的內容與主色：

| 元素 | 規格 |
|---|---|
| 底色 | 近黑 #0E0E0E ／ Hero 深藍 |
| Accent | 螢光綠（標籤、關鍵字、hover 反白） |
| 版面 | 全站四欄十字格線，交叉點有 `+` 標記 |
| 字體 | 標題 = variable sans（wght/wdth 可變）；UI 標註 = 等寬 mono；中文 = 思源黑體 / Noto Sans TC |
| 四角常駐 | 左上 logo、右上導覽、左下時間、中下滑鼠座標 |
| 游標 | 自訂 3D 箭頭，跟隨延遲 |
| 卡片 | 預設灰階，hover 才上色 |

### 一個設計判斷要先講

haoqi 的招牌動效是**文字亂碼解碼（scramble）**。這個效果**中文會很難看** — 中文字元寬度不一，亂碼跳動會讓整行寬度抖動，而且中文沒有「隨機字元看起來像亂碼」的視覺慣性。

我的做法：
- **英文標題、數字、mono 標註 → 用 scramble**（保留招牌感）
- **中文內文 → 改用「遮罩上滑 + 逐行淡入」**（節奏一致，但不抖）

這樣風格不破，中文也不會亂。
